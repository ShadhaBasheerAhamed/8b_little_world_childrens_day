# 8B — A Little World of Legends

A free, open-source, static website for Grade 8B Children's Day.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Enter a student's roll number (823–851) to open their profile.

No account, paid hosting, database, or build tools are required.

## Publish free
You can host this static site at no cost using:
- GitHub Pages: https://pages.github.com/
- Netlify Drop: https://app.netlify.com/drop
- Cloudflare Pages: https://pages.cloudflare.com/

Upload the extracted folder (or its contents) to one of those services. Their free tiers and terms may change.

## Included
- 29 Grade 8B student profiles with roll-number access
- Appreciation, strengths, future-self letter, magazine cover, character card and encouragement sections
- Cute animated galaxy decorations
- Teacher's Corner with printable QR cards

## Notes
- QR codes are generated by an external QR image service, so internet access is needed for QR images.
- Roll numbers are predictable and are not secure passwords. Do not use this for sensitive information.
- Student strengths/messages are positive starter copy; edit `app.js` to reflect each child's real individual qualities.
- Google Fonts are not required; the site uses system fonts and works offline.
